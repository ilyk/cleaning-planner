# Clara Avatar System with OpenAI Realtime Voice Chat

## 🎯 Overview

This PR implements a **world-class AI onboarding assistant** for the Cleaning Planner app, featuring real-time voice conversation powered by OpenAI's Realtime API.

**Key Achievement**: Sub-second conversational AI that gathers household information naturally, supporting 5 languages with full-duplex voice interaction.

## 🔧 Technical Implementation

### **Core Services** (5 new services)

1. **`OpenAIRealtimeService`** (775 lines)
   - WebSocket connection management
   - Bidirectional 24kHz PCM16 audio streaming
   - Turn management with versioning & cancellation
   - Atomic language switching (<300ms)
   - Session completion detection
   - Echo cancellation (VOICE_COMMUNICATION)

2. **`StreamingTTSService`** (227 lines)
   - Progressive audio generation (OpenAI TTS)
   - Sentence-by-sentence streaming
   - MediaPlayer queue management
   - Text chunking for UI updates

3. **`WhisperSTTService`** (198 lines)
   - OpenAI Whisper API integration
   - PCM to WAV conversion
   - Voice Activity Detection (VAD)
   - Continuous listening mode

4. **`TTSService`** (189 lines)
   - System TTS + OpenAI TTS integration
   - Voice style management
   - Caption synchronization
   - Fallback handling

## 🎯 Clara's Behavior

### **What Clara Does** ✅
- ✅ Greets user immediately in selected language
- ✅ Asks focused questions about the home (7 essential pieces)
- ✅ Redirects off-topic questions back to home info
- ✅ Maintains identity (always knows she's Clara)
- ✅ Keeps selected language (no random switching)
- ✅ Allows natural interruptions (full-duplex)
- ✅ Detects completion ("I'm done") and auto-navigates
- ✅ Sub-second response times
- ✅ No echo in speaker mode

### **What Clara Won't Do** ❌
- ❌ Make small talk (weather, sports, news, politics)
- ❌ Answer general knowledge questions
- ❌ Tell jokes or stories
- ❌ Offer to clean the house (info gatherer, not service provider)
- ❌ Switch languages randomly
- ❌ Forget her name or say she has no name
- ❌ Discuss her own capabilities or internal processes

### **System Prompt Structure**

Clara's laser-focused behavior is enforced through a **9-layer system prompt**:

1. ⚠️ **ABSOLUTE REQUIREMENTS** - Identity (Clara), Language, Role
2. 🏠 **APP CONTEXT** - What is Cleaning Planner
3. 📋 **PRIMARY GOAL** - Gather 7 essential pieces
4. 🎯 **THE 7 ESSENTIALS** - Specific information to collect
5. 🚫 **ABSOLUTE PROHIBITIONS** - What NOT to do (10 rules)
6. ✅ **REQUIRED BEHAVIOR** - How to act (short replies, redirect off-topic)
7. 📝 **OPENING SCRIPT** - Exact greeting (translated to selected language)
8. 🎬 **REDIRECTION TEMPLATE** - How to handle off-topic
9. ⚠️ **FINAL REMINDERS** - Reinforce critical rules

This structure ensures Clara never loses context, goes off-topic, or violates role boundaries.

## 💡 Design Decisions

### **Why OpenAI Realtime API?**

**Before** (GPT + TTS + Whisper):
- 3 separate API calls per turn
- 6-12 second latency
- Complex state management (310 lines)
- Echo issues
- No full-duplex

**After** (Realtime API):
- 1 WebSocket connection
- 320ms-1s latency
- Simpler code (127 lines)
- Built-in echo cancellation
- Full-duplex conversation

**Trade-off**: Higher cost ($0.02-0.05/session) but 10x better UX.

### **Why Strict System Prompt?**

Early testing showed GPT-4o/GPT-5 would:
- Go off-topic (weather, jokes, general chat)
- Offer cleaning services ("Would you like me to clean your kitchen?")
- Forget its name ("I don't have a name")
- Switch languages mid-conversation (Ukrainian → Czech)

**Solution**: 9-layer system prompt with explicit prohibitions and reminders.

**Result**: Clara is now laser-focused, maintains identity, and stays on-topic.

### **Why 3D Avatars?**

**Goal**: Make onboarding feel personal and welcoming.

**Options**:
1. No avatar (text only) - Cold, robotic
2. Icon avatar - Simple, lightweight
3. 3D avatar - Warm, engaging, modern

**Decision**: Implement all three with progressive enhancement:
- Default: 3D avatar (best experience)
- Fallback: Icon avatar (if 3D fails)
- Fallback: Text only (if user disables avatars)

**Result**: Beautiful 3D experience with graceful degradation.
