# Changelog

All notable changes to the Cleaning Planner project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project structure with multi-module architecture
- Core domain models (User, Household, Room, Task, Template, Schedule)
- Room database layer with entities, DAOs, and converters
- Retrofit networking layer with API interfaces
- Repository layer with offline-first sync strategy
- Material 3 theming with light/dark mode support
- Hilt dependency injection setup
- Navigation Compose infrastructure
- Basic app screens (Splash, Home with bottom navigation)
- WorkManager sync worker for background data sync
- English and Ukrainian internationalization
- README with comprehensive project documentation

### In Progress
- Authentication flow with magic link
- Household creation and join flow
- Room management with QR code generation
- QR scanning with CameraX and ML Kit
- Task creation and assignment
- Kid mode screen
- Family board with task management
- Printable PDF generation
